# Innewgen Brand Experience

Innewgen's multi-page brand experience for a software solutions studio. The site includes service and work pages, a light/dark theme toggle, responsive navigation, and a project inquiry flow.

## Development

Install [Bun](https://bun.sh), then install dependencies and start the local development server:

```sh
bun install
bun run dev
```

Useful scripts:

```sh
bun run build
bun run test
bun run lint
```
